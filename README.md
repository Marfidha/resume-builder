#  Resume Builder App

A full-stack resume builder application where users can create, edit, and download professional resumes.

##  Features

- User authentication (JWT)
- Create & edit resumes
- Live preview
- Download as PDF
- Multiple sections (Education, Experience, Skills)

##  Tech Stack

Frontend:
- React
- Tailwind CSS
- Lucide Icons

Backend:
- Node.js
- Express.js
- MongoDB
